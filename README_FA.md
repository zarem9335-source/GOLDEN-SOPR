# GOLDEN SOPR ✨

**GOLDEN SOPR** یک موتور تونل با کارایی بالا برای سرور ایران ⇄ خارج است که
با Go نوشته شده. یک باینری واحد، منوی تعاملی CLI **و** پنل وب امن. تم
طلایی در همه‌جا: طلایی (`#FFD700` / `#F5C518`) روی پس‌زمینهٔ تیره، هم در
ترمینال و هم در پنل وب.

> Based on BackPack by Amin Mohammadi (AminMGMT)
> https://github.com/AminMGMT/BackPack
>
> گلدن سوپر بر پایهٔ بک‌پک (AGPL-3.0) ساخته شده با نام و برندینگ خودش و
> ترنسپورت‌ها و قابلیت‌های جدید.

## ترنسپورت‌ها

همهٔ ۱۲ ترنسپورت معکوس بک‌پک، به‌علاوهٔ ترنسپورت‌های جدید:
TCP ،TCP Mux ،TCP + Stealth ،TCP + PCK ،UDP ،UDP + KCP + FEC ،UDP + QUIC
،WS / WS Mux ،WSS / WSS Mux ،xDi (ICMP) — و جدیدها: **grpc** ،**hq**
(QUIC + WS) ،**wg** (وایرگارد) ،**wg-gaming** (وایرگارد گیمینگ) ،**ss**
،**dns** ،**tls-camou** ،**bond** (باندینگ چندمسیره). حامل‌های HTTPS هم
هستند: Naive ،XHTTP ،REALITY / Vision.

## 🏆 wg-gaming — بهترین تونل برای وایرگارد گیمینگ

تونل جدید مخصوص ساخت **وایرگارد گیمینگ**:

- **وایرگارد L3 با Noise** — رمزنگاری‌شده، بدون توکنِ آشکار روی سیم.
- **Keepalive پنج ثانیه** — قطعی مسیر در کمتر از ۱۰۰ میلی‌ثانیه جبران
  می‌شود و بازی فریز نمی‌کند.
- **MTU ‏۱۲۸۰** — بدون فرگمنتیشن در مسیر ایران ⇄ خارج (علت اصلی
  لگ و پکت‌لاس در بازی).
- **DSCP EF** — اولویت پکت‌های بازی در صف.
- **ارسال دوتایی پکت‌های UDP بازی** — اولین نسخه می‌رسد و پکت گم‌شده
  دیگر یک تیک را نمی‌سوزاند.
- **FEC** — بازسازی پکت گم‌شده بدون ریتранسمیت.
- **پورت‌های بازی در اولویت** — پورت‌های استیم (27015–27020)،
  پلی‌استیشن/ایکس‌باکس (3074، 3478–3480) و بقیه.
- **Link Test خودش پیشنهاد می‌دهد** — با پرچم گیمینگ، اگر لاس بالای ۵٪ یا
  جیتر بالای ۳۰ میلی‌ثانیه باشد، `wg-gaming` را پیشنهاد می‌کند.

```bash
sudo golden-sopr   # ۱. Setup Iran → پریست: gaming (خودش wg-gaming را برمی‌دارد)
sudo golden-sopr   # ۲. Setup Kharej → لینک golden:// را پیست کن
```

## شروع سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/zarem9335-source/GOLDEN-SOPR/main/install.sh)
sudo golden-sopr
```

پنل وب پیش‌فرض: `http://127.0.0.1:2097` — کاربر `admin` و رمز
`admin123` (در اولین ورود عوض کنید). پورت ۲۰۹۶ عمداً استفاده نمی‌شود چون
روی خیلی از سرورها x-ui آن را گرفته است.

بات تلگرام: توکن و `owner_id` را در کانفیگ بگذارید، بعد
`golden-sopr telegram`. دستورها: `/status` ،`/tunnels` ،`/health`
،`/restart <name>` — فقط مالک.

لینک راه‌اندازی با طرح `golden://` است (پارسر `sopr://` و `backpack://`
را هم می‌پذیرد). کانفیگ: `/etc/golden-sopr/config.json`.
